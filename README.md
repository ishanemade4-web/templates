# Digital Safety Project

## About the Project
This project provides information and awareness about digital safety,
online security, privacy, and safe internet usage.

## Features
- Digital safety awareness
- Online privacy protection
- Password security
- Phishing awareness
- Safe internet browsing

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Purpose
The main purpose of this project is to create awareness about
digital safety and help users stay safe while using the internet.
